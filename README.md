# PocketAI

PocketAI is a personal finance and accountability application being developed in C#. The goal of the project is to create an AI-powered system that helps users manage money, build discipline, and stay focused on financial and personal goals.

The application currently allows users to track expenses, income, spending categories, and savings goals through a console-based interface. Future versions will expand into a full desktop and mobile application with AI-driven insights, habit tracking, and productivity features.

## Current Features

- Add, edit, and delete expenses
- Track expense categories and dates
- View total spending
- Filter expenses by category
- Track monthly income
- Create savings goals with deadlines
- Calculate savings plans and progress
- Input validation using `TryParse`

## Planned Features

- SQLite database integration
- AI-powered budgeting feedback
- Spending analysis and reports
- Habit and productivity tracking
- Goal accountability system
- Desktop and mobile support
- Authentication and cloud saving

## Technologies Used

- C#
- .NET
- Object-Oriented Programming (OOP)
- Console Application Development
- Collections and Lists
- Input Validation
- Git and GitHub

## Purpose of the Project

PocketAI was created to combine budgeting, self-discipline, and personal growth into one system. Instead of functioning as only a finance tracker, the long-term vision is to create an AI assistant that helps users improve their financial habits, productivity, and daily consistency.
